# Mysql日期

| 类型             | 取值范围                                                         | 格式                  | 占用字节 | 插入修改数据自动创建更新字段值 |
|----------------|--------------------------------------------------------------|---------------------|------|-----------------|
| datetime       | '1000-01-01 00:00:00.000000' to '9999-12-31 23:59:59.999999' | yyyy-MM-dd HH:mm:ss | 8    | 是               |
| timestamp（时间戳） | '1970-01-01 00:00:01.000000' to '2038-01-19 03:14:07.999999' | yyyy-MM-dd HH:mm:ss | 4    | 是               |
| date           | '1000-01-01' to '9999-12-31'                                 | yyyy-MM-dd          | 3    | 否               |
| time           | '-838:59:59' - '838:59:59'                                   | HH-mm-ss            | 3    | 否               |
| year           | '1901' to '2155'                                             | yyyy                | 1    | 否               |
