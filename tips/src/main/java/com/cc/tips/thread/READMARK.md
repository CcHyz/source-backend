### 多线程  
同步问题：

synchronized关键字是防止在多线程下引起逻辑结果出错或错乱而出生的  
## 主要是针对共享资源的控制保障该段代码块必须一个线程结束后才能进另一个线程。保障原子性  
### 语法:  
  
代码块同步  
synchronized(this){//this可替换为参数

}  
方法体  
public synchronized 返回值 方法名(){

}    
#### 注意：wait() 线程等待,notify() 唤醒同组等待线程,notifyAll() 唤醒同组所有等待线程，这些方法都要在synchronized内使用。  
名词解释：同组线程指操作得同一对象得多个线程
### 死锁  
当两个线程各占有一个资源后互相在等待各自释放各自的资源时便会引起死锁  
解决：通过有序方式解决锁竞争的问题  
例子：有1和2两个东西，线程A有1,然后获取2过程中,那么这个时候线程B就要先有1才能竞争2否则就等待。
